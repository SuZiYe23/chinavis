# 戏韵万象：京剧数据可视分析系统

一个面向京剧剧目数据、人物关系、主题结构和情节分析的专业可视分析平台。采用墨黑底色 × 朱砂配色 × 古金描边的国风视觉语言，融合故宫漆器美学与现代数据驾驶舱交互设计。

在线访问入口：[https://SuZiYe23.github.io/chinavis/](https://SuZiYe23.github.io/chinavis/)

## 页面功能

### 整体预览

时间轴朝代筛选 + 剧本索引网格 + 剧种分布柱状图（6 大类：历史戏/武戏/神怪戏/爱情伦理戏/公案戏/其他）+ 主题词云

### 具体剧目

剧本概览卡 + 角色表 + 人物关系力导向图（节点大小 ∝ 台词+场次，行当按形状区分）+ 情节走势折线图 + 主题词云 + 叙事事件列表

### 行当分析

桑基图（性别→身份→性格→表演→行当）+ 行当统计饼图 + 演化趋势堆叠面积图

### 角色关系

环形网络图 + 右侧三维度切换雷达面板（网络结构/角色维度/关系维度）+ 剧种筛选

### 主题结构

矩形树图（十大语义类别嵌套，主题词按频次分块，颜色按类别区分，支持点击下钻）
右侧面板：三维度组合模式分析（词词共现/类类共现），含频繁项集挖掘与提升度排序

### 综合分析

- **三者联动散点图**：冲突强度 × 角色网络规模 × 主题多样性，气泡颜色代表叙事结构类型（渐强高潮型/波浪渐进型/跌宕起伏型/先紧后松型/平稳推进型）
- **主题 × 冲突级别热力图**（可切换主题 × 关系类型）：十大语义类别在各冲突级别中的富集程度（提升度分析）
- **关系情绪演化折线**：不同剧种在五幕叙事中的冲突强度变化

│       ├── themeSunburst.js          # 主题矩形树图 + 组合模式挖掘

## 本地运行

项目无需 HTTP 服务器、无需 `npm install`，直接双击 `index.html` 即可。

## 技术栈

- **ECharts 5** + ECharts WordCloud（图表引擎）
- **原生 JavaScript**（无框架、无构建工具、无后端）
- 数据以 `<script>` 标签直接注入，运行于现代 Chrome/Edge/Firefox
- 部署于 **GitHub Pages**：[https://SuZiYe23.github.io/chinavis/](https://SuZiYe23.github.io/chinavis/)

## 数据质量

- 6 个核心 JSON 文件均为 1473 条记录（剧本数），相互可关联
- 前端通过 `data-js/*.js` 脚本标签加载，`DataStore` 全局对象提供统一查询接口
- 无需后端服务，纯前端离线可运行
